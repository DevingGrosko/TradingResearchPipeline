# Discord Archive

Utilities for exporting Discord commentary into structured research files.

## What This Folder Does

- Pulls channel history through `discord.py`.
- Stores message text, timestamps, attachments, embeds, and jump URLs.
- Writes source-backed JSONL and Markdown outputs for later analysis.
- Preserves provenance so each research item can be traced back to the original message.

## Data Policy

Generated archives, attachments, `.env` files, and bot tokens are excluded from this repository.
