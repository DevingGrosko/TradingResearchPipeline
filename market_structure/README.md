# Market Structure

Python utilities for working with OHLCV futures data and deriving market-structure features.

## What This Folder Does

- Builds continuous futures contract CSVs from Databento DBN files.
- Aggregates OHLC data into multiple timeframes.
- Computes partial candles for real-time-style analysis.
- Checks swing highs/lows and cross-market divergence conditions.
- Classifies trend/chop behavior with numeric time-series features.

## Data Policy

Raw DBN files, generated CSVs, and proprietary market-data exports are excluded from this repository.
